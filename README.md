# itmo-automl

## Что было сделано

В рамках проекта выполнено поверхностное исследование по задаче регрессии для
соревнования [Predict Calorie Expenditure](https://www.kaggle.com/competitions/playground-series-s5e5/overview).

Цель: спрогнозировать количество сожженных калорий на основе биометрии и параметров тренировки

Метрика: Root Mean Squared Logarithmic Error (RMSLE)

### Анализ данных (EDA)

- Проведен численный и визуальный анализ целевой переменной Calories
  - распределение, перцентили, IQR, выбросы
  - анализ в лог-пространстве с учетом RMSLE
- Проанализированы распределения признаков и их взаимосвязи с таргетом
- Построена корреляционная матрица
- Выявлены аномальные значения и подтверждено отсутствие пропусков
- Проверены гипотезы о влиянии возраста, роста и веса

### Бейзлайн с LightAutoML (LAMA)

Реализованы и сравнены две конфигурации:

- TabularAutoML
- TabularUtilizedAutoML

Использовалась 5-fold CV, ограничение по времени и стандартный пул моделей.

Результат LAMA существенно превзошел sample_submission, но оставил пространство для улучшений.

### Собственное решение

Обучены и оптимизированы модели LightGBM, CatBoost и XGBoost.

Для каждой модели использована кросс-валидация и выполнена оптимизация с Optuna.

## Выводы

AutoML дал быстрый и качественный бейзлайн, а ручной pipeline с аккуратным EDA
и оптимизацией гиперпараметров позволил получить лучший результат. Задача довольно
простая из-за малоко количества признаков и их понятной физической интерпретации,
поэтому она хорошо решается градиентным бустингом даже без генерации признаков.
